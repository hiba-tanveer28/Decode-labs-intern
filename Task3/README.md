Password Generator

A simple Password Generator application built with Python and Streamlit. This application creates strong and secure passwords based on the user's selected password length and preferences.

Users can:

Generate random passwords
Choose the password length
Include or exclude special characters
Generate secure passwords with at least one lowercase letter, one uppercase letter, and one number
Create strong passwords for better security

The project uses a separate Python file for the password generation logic and a Streamlit frontend for the user interface.

How to Run
Clone the repository:
git clone https://github.com/hiba-tanveer28/Decode-labs-intern/new/main/Task3

Open the project folder:
cd Task3

Install Streamlit:
pip install streamlit

Run the Streamlit application:
streamlit run apps.py

The application will open in your web browser.
