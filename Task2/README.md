Expense Tracker

A simple Expense Tracker application built with Python and Streamlit. This application helps users record and manage their daily expenses in an easy and organized way.

Users can:

Add new expenses
View all saved expenses
Update expense details
Delete expenses
Calculate the total amount spent

The project uses a separate Python file for the expense management logic and a Streamlit frontend for the user interface.

How to Run
Clone the repository: https://github.com/hiba-tanveer28/Decode-labs-intern/new/main/Task2
git clone 
Open the project folder:
cd Task2

Install Streamlit:
pip install streamlit

Run the Streamlit application:
streamlit run app.py

The application will open in your web browser.
