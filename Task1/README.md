 PROJEECT TITLE:
                  TO–DO LIST
                  
 DESCRIPTION:
          A simple Task Manager application built with Python and Streamlit. This application allows users to manage their daily tasks easily.
 Users can:
          Add new tasks
          View all tasks
          Update task title, status, or deadline
          Delete tasks
          Prevent duplicate tasks from being added

 The project uses a separate Python file for the task management logic and a Streamlit frontend for the user interface.

HOW TO RUN:

Clone the repository:
git clone (https://github.com/hiba-tanveer28/Decode-labs-intern/tree/main/Task1)

Open the project folder:
cd Task1

Install Streamlit:
pip install streamlit

Run the Streamlit application:
streamlit run app.py

The application will open in your web browser.

Technologies Used:
